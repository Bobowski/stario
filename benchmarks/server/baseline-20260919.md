# Server benchmarks — 2026-09-19 (Cython 4.2 merge)

Same-host complete `benchmarks/server` suite after merging `main` (4.2
`Route` / `Match` / `Assets` / `stario.json`) onto the Cython HTTP runtime.
Python httptools is gone; both Stario targets are Cython llhttp + nghttp2.

One worker each. `DURATION=10s` `RUNS=5` `WARMUP=1` `THREADS=2`
`CONNECTIONS=128` `UPLOAD_CONNECTIONS=32`, IQR trim. `wrk` 4.1.0, Python
3.14.7, 4 vCPU Intel Xeon. Git `3acbcec` on `cursor/cython-merge-main-b9bc`.

Runner log: `results/20260919T204120Z/` (started 20:41Z, finished 00:12Z).
Order: Stario CLI → Stario native → Socketify → Robyn → Granian RSGI →
Sanic → Django-Bolt → BlackSheep+Granian → BlackSheep+Uvicorn → FastAPI →

## vs Granian RSGI (this host)

Granian wins the GET microbenchmarks. Stario is even on small POST and
ahead once the body is tens of kilobytes or more. That split matches the
2026-08-29 cloud-agent host (`baseline-20260829.md`: Granian plaintext
**146k**, Stario **135k**) more than the later same-day pair where Granian
dipped to **115–117k** (`baseline-20260829-granian.md`).

Stario still leads every other Python framework on this suite, including
Socketify on GET and on every upload except the 2MB stream case (Socketify
**4,012** vs Stario **3,387**). Putting a framework on Granian ASGI
(BlackSheep) costs about **0.77×** Granian RSGI plaintext — Stario native
stays ahead of that stack on GET and on uploads.

CLI (`stario serve`) and `python -m stario_cython` are the same protocol;
treat them as one Cython number with a few percent of entry-path noise.

Do not compare absolute req/s to the 2026-08-28 lab machine.

## Follow-up (2026-09-20) — params LRU

4.2 dropped the 1024-entry `find_handler` LRU and only interned *static*
routes. The params bench is one URL (`GET /user/42`), so Cython-core used
to hit cache after the first request. After the merge, every params request
walked the trie and allocated `Match` + `MappingProxyType` (~1.0µs vs
~70ns for `/plaintext`). Granian RSGI is `path.startswith("/user/")` plus
`rsplit` (~0.1µs of Python).

Restored the LRU in front of the trie (`054afb1`). GET-only re-run, same
knobs, Granian first then Stario (`results/20260920T074228Z`):

| Server | Plaintext | JSON | Params |
| --- | ---: | ---: | ---: |
| Granian RSGI | **154,213 ± 3,948** | **154,023 ± 3,493** | **156,598 ± 3,428** |
| Stario Cython (CLI) | 144,551 ± 7,382 | 138,116 ± 3,103 | 138,845 ± 4,376 |
| Stario Cython (native) | 142,883 ± 845 | 137,045 ± 7,846 | 133,152 ± 4,655 |

Native / Granian after the fix: plaintext **0.93×**, JSON **0.89×**,
params **0.85×** (was **0.70×**). Params is back in line with the other
GETs. The leftover ~7–15% is the Rust HTTP server vs Cython llhttp +
`create_task` + `respond()`, not routing.
